# Rohit Rajvaidya | Backend Developer

A responsive personal portfolio highlighting backend development experience, projects, technical skills, education, and contact information.

## Features

- Responsive layout with section navigation
- Expandable project details
- Light and dark themes, with the selected theme saved in the browser
- Technology icons provided by Devicon

## Run Locally

Open `index.html` in a web browser. No build step or package installation is required. The technology icons are loaded from a CDN, so they require an internet connection.

## Files

- `index.html` - Portfolio content and page structure
- `style.css` - Layout, responsive styles, and light/dark theme colors
- `script.js` - Theme persistence, current year, and active section navigation
- `photo.png` - Profile photo
